Setting View

Multiple Markers

  • Use c() function to show as many markers as you want!
leaflet() |>
  addMarkers(
    lng = c(-93.18184, -93.182811), lat = c(44.459161, 44.461883),
    popup = c("Regents Hall", "Buntrock Hall")
  ) |>
  addProviderTiles(providers$OpenTopoMap)

Adding Shapes to Maps

addCircles(lng = -93.182811, lat =  44.461883, weight = 1,
    radius = 30
  )

Using Data With Leaflet

  • Leaflet can use coordinate data with any factors you want
  • For example:
colleges <- data.frame(
  school = c(
    "Carleton College",
    "Macalester College",
    "Gustavus Adolphus College",
    "College of Saint Benedict",
    "Concordia College"
  ),
  lat = c(44.4623, 44.9367, 44.3238, 45.5586, 46.8594),
  long = c(-93.1547, -93.1699, -93.9758, -94.3190, -96.7656),
  size = c(2107, 2068, 1852, 1356, 1910)
)

Using Data With Leaflet

  • Leaflet can use coordinate data with any factors you want
  • For example:
leaflet(colleges) |>
  addTiles() |>
  addMarkers(lng = ~long, lat = ~lat, popup = ~school)

Using Data With Leaflet

Using Data With Leaflet

  • You can even map variables to shapes corresponding to a certain variable
# Show a circle at each position
leaflet(data = colleges) |>
   addTiles() |>
   addCircleMarkers(~long, ~lat , popup = ~school, radius = ~size*0.01)

Using Data With Leaflet

Using Data With Leaflet

  • Or you can map variables to a color palette and create a legend
  leaflet(colleges) |>
  addTiles() |>
  addCircleMarkers(
    ~long, ~lat,
    popup = ~school,
    radius = 10,
    color = ~colorNumeric(
      palette = "viridis",
      domain = size
    )(size),
    fillOpacity = 0.8
  ) |>
  addLegend(
    position = "bottomright",
    pal = colorNumeric(
      palette = "viridis",
      domain = colleges$size
    ),
    values = ~size,
    title = "Student Population",
    opacity = 1
  )
