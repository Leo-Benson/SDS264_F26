Str_length gives the amount of characters in each song title, str_sub gives the year that the album was released for each song. str_view: the input is a column and something to look for and the output is a list showing the matches

typeof: the input is a variable (in this case a column using str_view) and the output is the type of variable that the column is

class: the input is a function (in this case str_view) and the output is the package and function

match = NA: shows all of output in addition to matches

html = TRUE: shows output as HTML

str_subset: input is column and something that must be true and output is the filtered results

str_detect: input is a column and something to match and the ouput is TRUE or FALSE depending on if the match applies

Tips with backreference:

  • You must use () around the the thing you want to reference.
  • To backreference multiple times, use \\1 again.
  • The number refers to which spot you are referencing… e.g. \\2 references the second set of ()
x1 <- c("abxyba", "abccba", "xyaayx", "abxyab", "abcabc")
str_view(x1, "(.)(.)(..)\\2\\1")
[1] │ <abxyba>
[2] │ <abccba>
[3] │ <xyaayx>
str_view(x1, "(.)(.)(..)\\1\\2")
[4] │ <abxyab>
str_view(x1, "(.)(.)(.)\\1\\2\\3")
[5] │ <abcabc>
